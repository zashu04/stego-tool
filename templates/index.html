HOW LSB STEGANOGRAPHY WORKS
01

Every pixel has 3 channels

Each pixel in an RGB image stores three 8-bit values — Red, Green, and Blue (0–255). That's 24 bits per pixel.

02

Modify the least significant bit

The last bit of each channel value has the smallest visual impact. Changing it shifts the color value by at most ±1, which is invisible to the human eye.

R: 10110110 → 10110111 182 → 183 (stores bit: 1)
G: 10011100 → 10011100 156 → 156 (stores bit: 0)
B: 11101111 → 11101110 239 → 238 (stores bit: 0)
03

Encode the full message

The message is first converted to binary (UTF-8). A 32-bit length header is stored first, followed by all message bits — 3 bits per pixel across the image.

04

Decode by reading LSBs

To extract, read the LSB from each channel in order. The first 32 bits give the message length, then read that many bytes to recover the original text.

Capacity formula: max_chars = (width × height × 3 − 32) ÷ 8 e.g. a 800×600 image → 180,000 characters
